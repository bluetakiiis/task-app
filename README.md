# TaskFlow

A simple task management web application for organizing your daily tasks.

**Live Website**: [Visit TaskFlow](https://your-website-url.com) (Coming Soon)  
**Source Code**: [github.com/bluetakiiis/task-app](https://github.com/bluetakiiis/task-app)

## Features

- Create, edit, and delete tasks
- Set due dates and times
- Organize tasks by categories
- Priority levels (High, Medium, Low)
- Mark tasks as completed
- Search and filter tasks
- User authentication

## How to Use

1. Visit the live website
2. Create an account or login
3. Start adding your tasks
4. Organize them by categories and priorities
5. Track your progress!

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB

## For Developers

Want to run this locally or contribute?

1. Clone the repository:

   ```bash
   git clone https://github.com/bluetakiiis/task-app.git
   cd task-app
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start MongoDB locally

4. Run the server:

   ```bash
   cd backend
   npm run dev
   ```

5. Open http://localhost:3000
